FIP 50 Tickets and reservations for MÁV and GySEV connections are sold on the MÁV booking website.

MÁV also offers an [app](https://www.mavcsoport.hu/mav-szemelyszallitas/belfoldi-utazas/mav-applikacio) through which FIP 50 tickets and reservations can be purchased.

## FIP 50 Tickets

FIP 50 Tickets for MÁV and GySEV connections are sold on the MÁV booking website. To add the FIP 50 discount, on the connection search page under _Passengers and Discounts_, the passenger overview must be opened. Only after entering the date of birth can the FIP 50 discount be added with _Add Discounts_. The discount option to select can be found in the table below.

| Journey       | FIP 50 class | 2nd class                                   | 1st / 1+ class                                 |
| ------------- | ------------ | ------------------------------------------- | ---------------------------------------------- |
| National      | 1st class    | "FIP 50% domestic discount 1st class (50%)" | "FIP 50% domestic discount 1st class (50%)"    |
| National      | 2nd class    | "FIP 50% domestic discount 2nd class (50%)" | "FIP 50% domestic discount 2nd class (50%)" \* |
| International | 1st class    | "FIP 50% domestic discount (50%)" †         | "FIP 50% domestic discount (50%)" †            |
| International | 2nd class    | "FIP 50% domestic discount (50%)" †         | not available online                           |

† For international journeys, the FIP 50 discount only applies to the Hungarian section.\
\* The class surcharge (_különbözeti díj_) is automatically added to the price — no separate option needs to be selected.

## Reservations

Reservations for MÁV and GySEV trains can be purchased online for 990 HUF. The option "I only need seat reservation" can be found in the connection information.

The correct discount option can be found in the following table:

| Journey       | FIP Coupon class | 2nd class                           | 1st / 1+ class                                             |
| ------------- | ---------------- | ----------------------------------- | ---------------------------------------------------------- |
| National      | 1st class        | "I only need seat reservation"      | "International ticket or pass, 1st class (free-of-charge)" |
| National      | 2nd class        | "I only need seat reservation"      | "I only need seat reservation" \*                          |
| International | 1st class        | "FIP free ticket (leisure journey)" | "FIP free ticket (leisure journey)"                        |
| International | 2nd class        | "FIP free ticket (leisure journey)" | not available online                                       |

\* The class surcharge (_különbözeti díj_) is automatically added to the price — no separate option needs to be selected.

For international journeys using FIP Coupons, you must hold FIP Coupons for all carriers along the route (e.g., for Budapest–Vienna, both an MÁV and an ÖBB Coupon are needed).

{{% highlight "important" %}}

The option "FIP egyországos szabadjegy" may still appear in the MÁV system. It is a legacy entry and **must not be used**, even though an infobox claims it is not valid for international travel. MÁV is working on removing it.
